Detailed Description

Structure containing the main and shadow colors, and the name string associated with an Item's subtype.

Shadow colors are always a darker tone of the main color. The colors are organized in the card_rarity_pal_gfx.png file which is organized like this:

  • 0 -> transparency
  • 1,2 -> Common Joker (blue)
  • 3,4 -> Uncommon Joker (green)
  • 5,6 -> Rare Joker (red)
  • 7,8 -> Legendary Joker / Tarot Card (purple)
  • 9,10 -> Planet Card (blue with a tint of green)
  • 11,12 -> Spectral Card (deep blue)
  • 13,14 -> Voucher (red with a tint of orange)
